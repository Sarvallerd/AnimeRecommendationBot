# Отзывы

В личном чате команда `/feedback` просит отправить отзыв одним текстовым сообщением. Команда работает и без предварительного `/start`: бот сохраняет настоящий профиль отправителя перед отзывом. Пустой текст, сообщение без текста и текст с NUL не записываются. Отзыв сохраняется целиком, со всеми пробелами и символами Unicode. После подтверждения записи бот отвечает: «Спасибо! Ваш отзыв сохранён.»

Если сохранение не удалось подтвердить, кнопка «Повторить отзыв» повторяет исходный текст с исходным ключом сообщения. При повторе одной и той же записи PostgreSQL возвращает уже сохранённую строку. Если запись подтверждена, а сообщение об успехе не доставлено, кнопка повторяет только сообщение об успехе. Повторная запись не выполняется.

Пока отзыв ожидает завершения, новое сообщение не заменяет его. `/feedback` открывает тот же отзыв и даёт новую кнопку повторения после перехода к другой команде. `/help` оставляет текущую кнопку действующей. `/cancel` закрывает диалог, но `/feedback` позволяет вернуться к сохранению исходного отзыва. Перезапуск бота удаляет незавершённое состояние и кнопки; уже сохранённый отзыв остаётся в базе.
